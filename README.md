## ⚡ Executive Summary

I am a cybersecurity researcher and software engineer specializing in cryptographic engineering, privacy-preserving distributed systems, and offensive security tooling. 

My work bridges theoretical cryptography with production software engineering:
* 🛡️ **Post-Quantum Cryptography (PQC):** Developing client-side lattice implementations (NIST FIPS 203 ML-KEM-768, Module-LWE stream ciphers) to protect against "Harvest Now, Decrypt Later" threats.
* 🔐 **Zero-Knowledge Cloud Systems:** Designing client-side encryption frameworks where service providers and databases have mathematically zero access to user plaintext.
* 🎯 **AI-Driven Security Tooling:** Orchestrating Large Language Models with DAST and SAST scanners for intelligent vulnerability triage and automated penetration testing.
* 🔬 **Reverse Engineering & Audit:** Binary and Android APK decompilation, firmware protocol analysis, and hardware/network penetration testing.
